# 🧪 Ivory E-Commerce — Manual QA Project

End-to-end Manual QA project performed on the **Ivory e-commerce website**, covering the complete testing process from test planning and execution to defect reporting and final release evaluation.

## 📌 Project Overview

The goal of this project was to evaluate the quality, usability, accessibility, compatibility, and functionality of the Ivory e-commerce platform through comprehensive manual testing.

The project includes:

- Test planning and test design
- Test Tree creation
- Functional Testing
- UI & UX Testing
- Accessibility Testing
- Compatibility Testing
- Performance Testing
- Internationalization Testing
- Test execution and documentation
- Defect reporting in Jira
- Test management using TestRail
- Release evaluation and recommendations

## 📊 Test Results

| Metric | Result |
|---|---:|
| Total Test Cases | 434 |
| Passed | 418 |
| Failed | 12 |
| Bugs Reported | 25 |
| Critical Bugs | 3 |
| Major Bugs | 5 |
| Minor Bugs | 17 |

## 🐞 Defect Management

During testing, **25 defects** were identified, documented, classified by severity, and supported with screenshots and reproduction details.

Several issues affected important areas of the user experience, including navigation, product pages, forms, accessibility, and other e-commerce functionality.
